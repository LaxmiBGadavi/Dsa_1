## Important Python Operations

| Operation | Purpose |
|---|---|
| `n % 10` | Extract last digit |
| `n // 10` | Remove last digit |
| `range()` | Iterate through numbers |
| `abs()` | Get absolute value |
| `** 0.5` | Calculate square root |

## Mathematical Formulas

**GCD:** Calculated using the Euclidean Algorithm.

**LCM:**

`LCM(a, b) = abs(a × b) / GCD(a, b)`
